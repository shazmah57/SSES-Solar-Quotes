# Company letterhead (JPG)

Save your letterhead as: **letterhead.jpg**

Required path:
- assets/images/letterhead.jpg

Optional (best app icon — square PNG, 512×512 or larger):
- assets/images/app_icon.png
  Then in pubspec.yaml set flutter_launcher_icons image_path to app_icon.png
  and run: dart run flutter_launcher_icons

After adding or replacing the file, run:
```
flutter pub get
```

Then hot restart the app.
